# 环境准备

项目使用已经创建好的 conda 环境 `vision-guard`。

## 1. 激活环境

```powershell
conda activate vision-guard
```

如果 `conda` 命令在当前终端不可用，请使用 Anaconda Prompt 或先初始化 PowerShell。

## 2. 必装依赖

```powershell
python -m pip install pywebview opencv-python numpy pydantic platformdirs Pillow pystray
```

用途：

- `pywebview`: 创建桌面窗口和 JS/Python 桥接。
- `opencv-python`: 摄像头采集、运动检测、视频录制和缩略图生成。
- `numpy`: OpenCV 图像矩阵依赖。
- `pydantic`: 配置模型和参数校验。
- `platformdirs`: 后续用于系统标准配置、日志、数据目录。
- `Pillow`: 读取桌面图标资源。
- `pystray`: 创建系统托盘图标和右键菜单。

## 3. 开发工具

```powershell
python -m pip install -r requirements-dev.txt
```

用途：

- `pytest`: 单元测试。
- `ruff`: 代码检查和格式约束。

## 4. Windows WebView2

Windows 上 `pywebview` 通常使用 Edge WebView2。新版 Windows 10/11 多数已经内置。

如果启动窗口时报 WebView2 相关错误，请安装 Microsoft Edge WebView2 Runtime。

## 5. 安装后验证

请在项目根目录运行：

```powershell
python -c "import webview, cv2, numpy, pydantic, platformdirs, PIL, pystray; print('env ok')"
```

如果输出：

```text
env ok
```

说明依赖已经满足，可以继续开发。

## 6. 当前暂不需要

MVP v1.0 暂不需要这些依赖：

- `flask`
- `fastapi`
- `requests`
- `httpx`
- `PySide6`
- `Vue`
- `Vite`
- `Node.js`

后续如果加入 Webhook、复杂设置页或前端构建链，再单独评估。
